# ClockOut

A free, responsive logout-time calculator. Enter a login time and required working duration to calculate the expected logout time in both 12-hour and 24-hour formats.

## Features
- Mobile-friendly dark interface
- Custom work duration and quick presets
- 12-hour and 24-hour time display
- Supports logout times that fall on the next day
- Copy result and reset controls
- No break-time calculation
- All calculations happen locally in the browser

## Publish free with GitHub Pages
1. Sign in to GitHub and create a new public repository named `clockout`.
2. Upload `index.html`, `favicon.svg`, `manifest.webmanifest`, and `README.md` to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)` folder, then save.
6. After GitHub Pages finishes publishing, use the URL shown in the Pages settings.

No build tools or server are required.

## Important
ClockOut calculates elapsed time only. It does not add breaks or determine official attendance compliance; users should follow their employer's policy.
